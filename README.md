# Log Traffic Analyser

A script that parses traffic logs from a data source/log aggregator, and analyses it to see inbound traffic patterns

## Getting Started

Clone this repo and install dependencies:

```sh
git clone git@github.com:CyntiBinti/log-traffic-analyser.git && cd log-traffic-analyser && npm i
```

## Prerequisites before running

- You'll need to create a local `raw-data.txt` file in the `src` directory, and add your freshly exported log data into it (NB: export as JSON)

## Usage

Run the following command to start the script:

```sh
npm run start
```
